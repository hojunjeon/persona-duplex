# 사용자 음성 제로샷 복제의 범위와 한계

## 입력되는 목소리 정보

Persona Duplex는 참조 WAV와 그 음성에서 실제로 읽은 정확한 대본을 Qwen3-TTS Base 모델에 전달합니다. 공식 `qwen-tts` backend에서는 `create_voice_clone_prompt(..., x_vector_only_mode=False)`로 reusable full-ICL prompt를 만들고, `faster-qwen3-tts` backend에서는 공개 API대로 `ref_audio`와 `ref_text`를 스트리밍 생성 호출에 직접 전달합니다. 두 경로 모두 단일 화자 임베딩만 쓰는 x-vector-only 모드가 아니라 참조 내용과 음향 문맥을 함께 쓰는 경로를 목표로 합니다.

```text
reference.wav + exact transcript
  → 음향/화자/운율 조건 토큰
  → full-ICL 음성 조건
  → backend별 prompt/reference cache
  + 새 텍스트
  → 합성 음성
```

## 잘 복제되는 요소

깨끗한 기준 음성에서는 보통 다음 요소가 가장 잘 전달됩니다.

- 화자의 전반적 음색
- 기본 음역과 공명 특성
- 발화 속도와 에너지의 일부
- 억양·호흡·리듬의 일부
- 기준 음성에 나타난 발성 스타일

## 보장할 수 없는 요소

- 모든 문장에서 완전히 같은 피치 곡선
- 기준에 없던 감정 연기
- 속삭임·고함·울음 같은 극단적 발성
- 긴 대화 전체의 완벽한 동일성
- 사용자의 실제 기억·성격·신원
- 청취자 누구에게나 구분 불가능한 동일성

제로샷 모델은 새 문장의 언어 내용과 운율을 생성해야 하므로 기준 오디오를 그대로 복사하는 것이 아닙니다.

## 품질을 높이는 녹음

- 8~20초
- 한 사람만 발화
- 무배경 음악
- 같은 마이크 거리와 일정한 게인
- 문장 끝을 잘라먹지 않음
- 실제 발화와 대본이 정확히 일치
- 최종 봇이 사용할 톤으로 읽음
- 과도한 denoise, reverb, pitch correction을 피함

## 말투까지 더 고정하려면

한 프로필에 모든 감정을 섞기보다 용도별 프로필을 따로 등록하는 편이 안정적입니다.

```text
neutral-profile     평상시 대화
calm-profile        차분한 설명
energetic-profile   높은 에너지
```

현재 UI는 대화 시작 때 한 프로필을 선택합니다. 세션 중 동적 프로필 전환이 필요하면 LLM 출력에 감정 태그를 노출하지 말고, 별도의 정책 모듈이 프로필 ID를 선택하도록 확장하는 편이 안전합니다.

## 안전과 동의

본인 음성 또는 명시적으로 허가받은 음성만 등록해야 합니다. 프로필 메타데이터에는 동의 확인 여부가 기록됩니다. 공개 서비스로 배포할 때는 인증, 삭제, 감사 로그, 합성 음성 고지 정책을 추가해야 합니다.
